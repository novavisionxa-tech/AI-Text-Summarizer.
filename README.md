# AI-Powered Text Summarizer
A simple, efficient Python tool to summarize long texts using Natural Language Processing (NLP). 

## How it works:
- Tokenizes the text into sentences and words.
- Filters out common stop words.
- Calculates word frequency to score sentences.
- Extracts the most important sentences as a summary.

## Prerequisites:
- Python 3.x
- NLTK library (pip install nltk)

## Usage:
Simply pass your paragraph to the `summarize_text` function, and it will return a concise version of your text.
